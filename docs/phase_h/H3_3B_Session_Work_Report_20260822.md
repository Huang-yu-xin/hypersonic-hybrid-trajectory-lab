## 3. Phase 1 设计与结构性缺陷的发现

### 3.1 缺陷的数学内容

设计期 scratch 核验（用户明确"不要马上写代码"之后的数学验证，非实验）发现：**上游计划 §6.1 的协议示例 $q=\mathcal N(x^\ast,I)$ 会使核心观测量恒为零**。改写一切的关键恒等式：

$$
x^*=\operatorname{proj}_A(0),\qquad x_L=\operatorname{proj}_A(-m)
\ \Longrightarrow\
D_L=\lVert\operatorname{proj}_A(-m)-\operatorname{proj}_A(0)\rVert,
$$

即 $D_L$ 是 $(A,m)$ 二元组的属性而非系统单独属性。**凸集引理（三行证明）**：$A$ 闭凸时法锥条件给 $\langle x^\ast,z\rangle\ge\beta^2$，于是 $\lVert z+x^\ast\rVert^2\ge\beta^2+2\beta^2+\beta^2=4\beta^2$，等号唯一在 $z=x^\ast$——**MPP 锚定下 $D_L\equiv0$ 对一切凸失效集成立**。数值确认：连 frozen B 构型本身在该约定下 $d_L=0$。逃逸通道唯一：非凸"包裹"（环形反例 $D_L=2$）。

### 3.2 影响评估（六层面）

致命项：若按原协议跑完全量，Figure A 全零平线 → Gate 假性失败 → "曲率不控制 alignment"假阴性 → Axis 1 无谓降级二值 → 污染 Phase 3。其余：Axis 1 须重新形式化为协议相对量；语料可比性约束（frozen $d_L$ 全部生活在 $\mu_{base}$ 约定）；Phase 2 豁免（cov 杠杆改形状不移动投影查询点）——两杠杆不对称性被锐化为结构命题；正向转化——缺陷升格为定理候选。

### 3.3 初步修复（DV1–DV3）

主约定改 frozen $\mu_{base}$（可比性+信号存在）；成功标准从"临界 $\beta\kappa_c$"改为 onset 描述子；双约定分开落盘；$m=x^\ast$ 降为对照层——其预期恒零本身成为定理的实验确认项。

## 5. Phase 1 执行（两次设计期拦截）

**拦截一（dry-run 前，DV7）**：首版把钉参条件放网格桥接层——dry-run 暴露网格层 $\lVert x^\ast\rVert$ 关于 $c$ 是**阶梯函数**（离散 argmin 跳变），二分不适定（收敛到台阶边缘 c=0.9968）。裁定：连续层钉参（光滑适定）+ anchor config **硬编码 frozen 边界 c=1.0** 逐位复现（其连续 β 与全局 β_B 差 0.309%，显式落盘）。

**全量结果**（15 configs × 4 seeds，wall 112s）：$d_L$ 从 0.0162 单调渐变生长至 0.998（Spearman 1.000、零违反）；双支结构于 $a^\ast{=}0.05306$ 连续切换；$\gamma_{sat}=1.265$ 证实饱和尺度修正；辅约定全网格 $\le1.5\times10^{-7}$（定理 4.4 确认）；union 3.1887；第二族方向一致（r=1.5 高 γ 不可达如实入档）。

**拦截二（Gate C4 失败的处置）**：样本池点估计 anchor 四 seed 极差 0.482≫0.05。根因：任务书把**网格层**稳定性误引到**样本层**——而后者正是 H3-3A 证明不稳定的对象。按 F4 预案 deterministic 层权威 + v2.2 勘误 + 报告专节披露。这一"失败"反而构成语料既有结论的独立再现。
