## 0. 文档定位与版本记录

**结论先行（v2 定位）。** 本任务书检验曲率轴 $\gamma=\beta\kappa$ 是否系统性控制 alignment。设计期解析核验与外部数学评审共同产生了两个先于实验的结构性结论，构成本任务书的科学背景：

1. **盲性定理（已证，Theory Extension 定理 4.4）**：凸失效集 + proposal 锚在 MPP（$m=x^*$）时，$x_L=x^*$ 对一切合法协方差成立——**标准 MPP 居中 IS 对凸失效集的 variance geometry 结构性失明**。这不是缺陷陈述，而是本阶段最强的定理级产出：它为 leakage-aware（偏移锚定）proposal 提供必然性论证。
2. **对 H3-2 经验判据的正面修正（设计期核验支持，待正式实验确认）**：分离不存在"临界曲率"——它对任意 $a>0$ 存在、随 $\gamma$ 近线性生长、在 $\gamma\sim1$ 处趋于饱和。$\beta\kappa\gtrsim1$ 是**饱和尺度 $\gamma_{sat}$ 的经验标志，不是起始阈值**。

因此 Phase 1 的主约定必须采用语料统一的偏移锚 $\mu_{base}$；$m=x^*$ 协议降为对照层，其恒零是定理 4.4 的实验确认项。

## 3. 扫描轴冻结

### 3.1 轴定义（不变）

$$
\gamma=\beta\kappa,\quad \beta=\lVert x^*\rVert,\quad \kappa=|h''(t^*)|/(1+h'(t^*)^2)^{3/2}.
$$

### 3.2 控制方式（不变）

唯一旋钮 $a$；钉死 $\beta\equiv\beta_B=1.483825$（逐位等于 frozen B/S2 的 $\lVert x^*\rVert$，每 config 二分求根 $c(a)$，容差 $\le10^{-10}$）、$v\equiv1.5$、$d=4$、proposal 规则与样本量。**钉 $\beta$ 只锁模长；$x^*$ 切向位置随 $a$ 漂移属被测几何的一部分，如实落盘**（评审 Q6 指出的混淆由第二族 probe 分离，见 §4.4）。

### 3.3 网格（v2：15 configs）

$$
a \in \{\,0,\ 0.01,\ 0.02,\ 0.05,\ 0.05306,\ 0.075,\ 0.1,\ 0.2,\ 0.35,\ 0.5,\ 0.75,\ 1.0,\ 1.5,\ 2.0,\ 3.0\,\}
\qquad(\text{共 }15\text{ configs})
$$

- $a=0$：线性极限。主约定解析值 $d_L=\delta_0=0.016175$（镜像查询点 $(1.5,0)$ 落在半空间内部，$x_L=(1.5,0)$）；辅约定解析值 $D_L^\star=0$（定理 4.4）。
- $a^\ast=0.05306$：**解析分支点**（§3.4），必配 config；其与近邻 $a=0.05$（左支末）和 $a=0.075$（右支始）共同夹住机制切换两侧。
- $a=0.5$：anchor config，$c(0.5)=1.0$ 精确退回 frozen B 边界，用于锚点复现校验（Gate C1）。
- 其余格点在低 $a$ 端加密（起始段形状是主要观测量之一）。

**盲化加密规则（预注册，仅一次）**：粗网格完成后在相邻 $|\Delta d_L|$ 最大区间均匀插入 ≤4 点；规则先于任何下游分析执行并记录。除此之外禁止改网格。

### 3.4 解析分支点（v2 新增）

主约定的镜像查询点是 $-\mu_{base}=(1.5,\,0)$。其与 $A_{S2}(a,c)$ 的关系存在解析切换：

$$
c(a)+2.25a\ \lessgtr\ 1.5
$$

- **左支（$a<a^\ast=0.05306$，内点峰体制）**：$(1.5,0)\in A_{S2}$，高斯核模在失效集内部，$x_L\equiv(1.5,0)$ 冻结于内点；$d_L(a)=\lVert x^*(a)-(1.5,0)\rVert$，其增长完全来自 $x^*$ 的漂移（锚几何主导，非曲率主导叙事）。
- **右支（$a>a^\ast$，边界投影体制）**：$(1.5,0)\notin A_{S2}$，$x_L$ 为边界上受约束最大，随 $a$ 移动（curvature-driven）。
- $x_L$ 在 $a^\ast$ 处**连续**（内侧点与外侧投影在极限重合），但机制切换必须分开报告，禁止跨 $a^\ast$ 盲拟合。

## 4. 参数化边界族冻结

### 4.1 主族（不变）

$h_a(t)=c(a)+a(t-1.5)^2$；$a=0.5,c=1$ 逐位退回 frozen B；S1/nominal 保持 frozen 原式。顶点偏移 $v=1.5$ 钉死（对称族 $v=0$ 两约定下均恒零，设计期已核验；偏移是 mismatch 的必要结构要素）。

### 4.2 合法性与良定性（不变 + 内点分支）

$\Sigma\succ\tfrac12I$ 全程满足；每 config 记录极小点唯一性 `gap_ratio`（阈值 1.05，C1 audit 平坦景观判据）。**Layer-D 必须实现 §5.1 的内点分支判定。**

### 4.3 为什么保留单一旋钮（回应评审 Q6 的部分）

主族承担"同族内曲率响应"测量；"曲率 vs 锚–边界几何漂移"的混淆由 §4.4 第二族 probe 分离，不在主族内加参数。

### 4.4 第二非二次族稳健性 probe（v2 新增，Layer D only）

**族定义**：$h^{(r)}_b(t)=c+b\,|t-1.5|^{\,r}$，$r\in\{1.5,\ 3\}$（均凸，$r=3$ 含强不对称三阶行为）。**配置求解**：每个 $(b,r)$ 组合解二元方程组使 $\lVert x^*\rVert=\beta_B$ 且 $\kappa_{MPP}=\gamma^{tgt}/\beta_B$，目标 $\gamma^{tgt}\in\{0.274,\ 0.848,\ 1.349\}$（取自主族 $a\in\{0.1,0.5,2.0\}$ 的实测 $\gamma$）。共 $2\times3=6$ 个确定性 config。**目的**：若两族在同 $\gamma$ 处给出定性一致的 $d_L$（单调生长–饱和、同量级），则"曲率控制 alignment"不依赖二次性；若显著分歧，如实报告族的依赖性并降级结论。本 probe 不进入 Figure A 主曲线，作稳健性附录。

## 5. 计算协议冻结

### 5.1 Layer D（deterministic 主层）——v2 关键修订：内点分支

对每个 config 与每种约定，计算受约束最大：

```
输入: 边界 h, c;  核中心 s (主约定 s=-μ_base=(1.5,0); 辅约定 s=-x*(a))
若 s ∈ int(A_S2):        x_L = s            (内点峰: ρ_V 无约束模即全局最大)
否则:                    x_L = argmin_{t∈boundary} ‖z(t)-s‖   (边界受约束最大)
                          [粗网格 3e5 点 + bounded 精化, 容差 1e-12]
输出: x*, x_L, d_L, gap_ratio, 所处分支标记 {interior | boundary}
```

**v1 教训（如实披露）**：v1 设计期 scratch 只做边界极小化且硬编码了 $a=0$ 行为 0——前者在内点体制下方法错误、后者数值错误（正确值 0.0162）。正式脚本以上述分支伪文为准，dry-run 必须复算 §5.3 修正表全部行。

### 5.2 Proposal 约定（不变 + 偏移声明）

- **主约定**：$q=\mathcal N(\mu_{base},I)$，$\mu_{base}=(-1.5,0,0,0)$ frozen 全程不变。**显式声明**：$\lVert\mu_{base}\rVert-\beta_B=0.016175$ 的基线偏移存在于全部主约定数据点中（包括 $a=0$ 的 $d_L=0.0162$）；它是语料历史锚的属性，不做归零校正，只在报告与 Gate 阈值中显式计入。
- **辅约定（对照层，Layer D only）**：$q=\mathcal N(x^*_{(a)},I)$ 每 config 重心；预期 $D_L^\star\equiv0$（定理 4.4 数值确认）。
- 两约定分开落盘（$d_L$ vs $D_L^\star$），禁止混用。

## 7. Gates（v2：阈值与描述子修订；先于实验冻结）

### Gate P1-A — 过渡存在性 + 形态分类

- **A1（两端可达）**：$d_L(a{=}0)=0.016175\pm10^{-3}$（主约定解析值复核）**且**存在 config 满足 $d_L\ge\delta_{mis}=0.1$。（v1 的 aligned 阈值 $\delta_{alg}=10^{-3}$ 因基线偏移失效，删除——本族不存在扩展 aligned 平台，这本身是被报告的结论。）
- **A2（特征尺度）**：报告 $s_0$（曲率支低 $\gamma$ 端线性拟合斜率，拟合窗 $[\gamma^\ast,\ 2\gamma^\ast]$）与 $\gamma_{sat}$；可选 Michaelis 拟合三参数。**禁止**把拟合反向外推到拟合窗外。
- **A3（形态分类）**：相邻 config $|\Delta d_L|\le0.3$ ⟹ gradual；任一跳变 $>0.3$ ⟹ jump/bifurcation（触发 F3）。分支点 $a^\ast$ 处的机制切换**不计为跳变**（解析已知连续）。

### Gate P1-B — 单调性

- deterministic 层 $d_L$ 对 $\gamma$ Spearman ≥ 0.9；
- 相邻违反非减幅度 ≤ max($10^{-3}$, 3× seed 级 MAD)；**允许在 $a^\ast$ 处出现折坡**（斜率变化不算违反单调）。

### Gate P1-C — 稳健性与对照

- **C1（锚点复现）**：anchor config 网格层 $d_L=0.7751\pm0.01$；连续层 $0.740\pm0.05$。
- **C2（解析零/偏移复核）**：辅约定 $a=0$：$D_L^\star=0$（容差 $10^{-6}$，定理 4.4）；主约定 $a=0$：$d_L=0.016175\pm10^{-3}$（解析 $\delta_0$）。
- **C3（跨 η）**：分类在 $\eta\in\{0.5,0.9\}$ 与 0.8 一致 ≥90% configs。
